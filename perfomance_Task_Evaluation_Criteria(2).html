2. 최종 논술 상세 채점 기준 (8점 만점)
💡 평가 핵심: 단순 요약이 아니라 '자기 주장(판단)'과 '선택한 개혁의 한계 인정'이 포함되었는가?
점수 등급 평가 기준 비고
8점 탁월 모든 요소 충족 + 논리적 완결성
• 필수 5요소(분석, 비교, 자기판단+한계인정, 페르소나, 규칙)를 모두 포함함
• 문단 간 연결이 매끄럽고, 역사적 근거(자료 활용)가 설득력 있음 		Perfect
7점 우수 필수 요소 충족 + 약간의 아쉬움
• 필수 5요소는 모두 포함했으나, '한계 인정'이 형식적이거나
• 자료 활용이 구체적이지 않고 일반적인 서술에 그침 		-1
6점 보통 필수 요소 1개 누락
• 전체적인 흐름은 좋으나, '한계 인정' 또는 '소통 규칙' 중 하나가 빠짐
• 또는 자기 주장의 근거가 빈약함 		-2
5점 미흡 필수 요소 2개 누락
• 사건의 요약(분석/비교)에만 치중하고 자기 생각이 없음
• 또는 페르소나 관점이 완전히 무시됨 		-3
4점 부족 내용 빈약
• 분량은 채웠으나 핵심 질문(어떤 개혁이 적합했는지)에 대한 답이 없음
• 역사적 사실 오류가 글의 논지를 흐릴 정도로 심각함 		-4
3점 최소 불성실
• 500자 미만이거나, 제시된 자료를 그대로 베껴 쓰기만 함
• 주제와 무관한 내용을 서술함 		기본점수
📌 '한계 인정'이란?
자신이 더 적합하다고 선택한 개혁의 한계점(문제점)을 함께 밝히는 것.
※ 다른 주제 예시: "신라의 삼국통일이 의의가 크다고 생각한다. 다만, 외세의 힘을 빌렸고 대동강 이북 영토를 잃었다는 점은 한계로 인정한다."

같은 문장을 무의미하게 반복하여 분량을 늘린 경우
4. 점수 산출 예시

📝 학생 A의 경우

  • 1단계 (페르소나): 선택 후 끝까지 유지함 → 2점
  • 2단계 (자료 분석): 자료 인용하여 논리적으로 서술 → 2점
  • 3단계 (기초 사실): 3문장 모두 정확함 → 2점
  • 4단계 (비교표): 차이점 2개 썼으나 기준이 모호함 → 3점
  • 5단계 (규칙): "싸우지 말자"라고만 씀(추상적) → 1점
  • 6단계 (논술): 다 썼는데 '한계 인정'이 형식적임 → 7점
총점: 2 + 2 + 2 + 3 + 1 + 7 = 17점

📝 학생 B의 경우

  • 1단계 (페르소나): 선택만 하고 이후 드러나지 않음 → 1점
  • 2단계 (자료 분석): 자료 인용 없이 막연히 서술 → 1점
  • 3단계 (기초 사실): 연도 오류 1개 → 1점
  • 4단계 (비교표): 공통점+차이점 명확함 → 4점
  • 5단계 (규칙): 구체적인 규칙 2개 제시 → 2점
  • 6단계 (논술): 한계 인정과 소통 규칙 누락 → 5점
총점: 1 + 1 + 1 + 4 + 2 + 5 = 14점
5. 선생님 팁 (채점 포인트)

💡 변별력의 핵심: '한계 인정'

  • 상위권 학생들은 자기 주장의 약점을 스스로 인정하는 균형 잡힌 시각을 보여줍니다.
    ※ 다른 주제 예시: "서희의 외교 담판이 더 효과적이었다고 생각하지만, 군사력 없이 외교만으로는 거란의 재침을 완전히 막기 어려웠다는 한계는 인정한다."
  • 중위권은 한계를 언급하긴 하나 "조금 문제가 있었다" 수준으로 형식적입니다.
  • 하위권은 자기 주장만 있고 한계 인정이 없거나, 아예 자기 주장 자체가 불분명합니다.

💡 페르소나 채점 기준

  • 2점: 글 속에서 ※ 다른 주제 예시: "나는 백제 유민으로서~", "신라 귀족인 나로서는~"와 같이 입장이 명시적으로 드러남
  • 1점: 1단계에서 선택만 하고 이후 글에서 전혀 언급 없음

💡 비교 분석 4점 vs 3점

  • 4점: ※ 다른 주제 예시: "대응 방식에서 차이가 있다. 서희는 외교 담판으로 해결했고, 강감찬은 군사적 승리로 해결했다."처럼 기준이 명확
  • 3점: ※ 다른 주제 예시: "서희는 말로 했고, 강감찬은 싸워서 이겼다."처럼 기준 없이 결과만 나열
6. 사실 오류 체크리스트 (3단계 감점 사유)
✗ 오류 내용 정답
✗ "갑신정변이 1894년에 일어났다" 1884년
✗ "갑오개혁이 1884년에 일어났다" 1894년
✗ "갑신정변이 성공하여 제도가 바뀌었다" 3일 만에 실패
✗ "갑신정변은 청나라의 도움으로 진행되었다" 일본의 도움 (청나라가 진압)
✗ "갑오개혁은 외세 개입 없이 자주적으로 진행되었다" 일본의 군사적 영향 아래 진행
✗ "동학농민운동과 갑신정변이 같은 해에 일어났다" 동학농민운동 1894년 / 갑신정변 1884년
📌 채점 시 유의사항

• "어떤 개혁이 적합했을지"는 정답이 없음 → 근거의 논리성과 한계 인정 여부만 평가
• 페르소나는 1단계 선택과 5~6단계 서술의 일관성 확인
• 자료 활용은 "베끼기"가 아닌 "해석"이 있어야 2점
• AI, 번역기, 대필 사용 및 답안 공유 적발 시 재작성 또는 0점 조치
• 과정 최저 5점 + 논술 최저 3점 = 전체 최저점 8점
